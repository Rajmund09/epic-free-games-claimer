# Epic Free Games Claimer 🎮

A semi-automated Python script that helps you **safely claim free games from the Epic Games Store** using Playwright.

> 🔐 Login is done manually to avoid account or security issues.

---

## 🚀 Features
- Opens Epic Games Free Games page automatically
- Manual login (no credentials stored)
- Detects free game pages
- Skips already-owned games
- Safety limit to avoid mass actions
- Clear logs and safe exit handling

---

## 🛠 Requirements
- Python 3.9+
- Google Chrome / Chromium
- Playwright

---

## 📦 Installation

```bash
git clone https://github.com/your-username/epic-free-games-claimer.git
cd epic-free-games-claimer
pip install -r requirements.txt
playwright install

## ▶️ Usage

python epic_free_games.py


- Script opens Epic Games Store
- Login manually
- Return to terminal and press ENTER
- Choose which games to claim (Confirm, then add to library.)
